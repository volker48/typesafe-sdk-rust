What the experiment settled
Recommendation: use json! plus typed conversion now; add a fallible SDK constructor with precise input diagnostics next. Keep typed Rust for programmatic composition. A custom nested macro grammar does not solve the error-repair problem.
The pair constructor rejects duplicate names, but the tiny prototype macro covers literal keys only. Macro hygiene, arbitrary expressions, and production-quality diagnostics were not established.
